시작하기 전에 꼭 알아둘 3가지

① 펜이 켜져 있으면 칩을 눌러도 포장 완료가 안 됩니다.

② 주문 취소는 묻지 않고 바로 됩니다.
취소한 직후 화면 아래에 되돌리기 가 잠깐 나옵니다. 그 안에 누르면 원래대로 돌아옵니다.
③ 잘못 눌러도 대부분 되돌릴 수 있습니다.
포장 완료는 칩을 한 번 더 누르면 풀리고, 펜은 되돌리기가 있고, 상차 스캔도 취소할 수 있습니다.

따라하기

1

업체를 고릅니다

화면 위 날짜가 오늘인지 보고, 왼쪽 목록에서 미기록 업체를 누릅니다. 위에서부터 차례로 하면 됩니다.

주문이 모두 취소된 업체는 목록에서 빠집니다. 과거 날짜는 보기만 됩니다(설정에서 "과거 날짜 편집"을 켜야 고칠 수 있습니다).
2

추천이 맞으면 바로 제출

위쪽 박스 추천의 1순위가 현장 포장과 같으면 아래 맞아요. 제출하고 다음 업체 를 누릅니다. 제출되면 다음 미기록 업체로 저절로 넘어갑니다.

3

다르게 담았다면 — 상품을 눌러 옮깁니다

활전갱이 20미누르면활전갱이 담을 박스 12에서2누르기
  • 일부만 담기: 이동 줄의 담을 수량 칸에 숫자를 쓰고 박스 번호를 누릅니다. 남은 수량은 "아직 담지 않은 상품"에 남습니다.
  • 새 박스에 담기: 이동 줄의 새 박스… 에서 종류를 고릅니다.
  • 실측 kg: 이동 줄의 실측 kg 칸에 무게를 적을 수 있습니다(선택).
  • 다른 박스로 옮기기: 박스에 들어 있는 상품을 눌러도 같은 이동 줄이 켜집니다. 지금 있는 박스 번호는 흐리게 막혀 있습니다.
  • 마우스로 상품을 끌어다 박스 줄에 놓아도 됩니다.
4

잘못 담았을 때 — 상품 하나만 빼기

방어 3kg상품 옆 x 를 누르면방어 3kg이 "아직 담지 않은 상품"으로 돌아옵니다

박스는 그대로 두고 그 상품만 빠지니, 다시 눌러서 다른 박스에 담으면 됩니다. 박스 전체를 빼려면 줄 끝의 를 누르세요(담긴 상품은 "아직 담지 않은 상품"으로 돌아옵니다).

박스가 비면 제출이 안 됩니다. "N번 박스가 비어 있습니다. 상품을 담거나 박스를 지워주세요." 라고 나오면 상품을 담거나 그 박스를 빼세요.
5

박스가 모자라면 — 박스 추가

맨 아래 + 박스 추가… 에서 박스 종류를 고르면 한 줄이 늘어납니다. 박스 종류는 줄 가운데 선어박스 ▾ 에서 바꿀 수 있고, 담긴 상품은 그대로입니다.

물봉이 필요한 상품이 물봉용이 아닌 박스에 들어가면 물봉 필요 경고가 뜹니다.

6

(필요할 때) 합포장 — 같이 내보낼 박스 묶기

박스가 2개 이상일 때 나오는 합포장 줄에서 같이 내보낼 박스 번호를 두 개 이상 누르고 묶기 를 누르면 1·2번 으로 묶입니다. 묶음 옆 ✕ 로 풀 수 있습니다. 묶음은 제출할 때 함께 저장되고, 라벨에 "합포장 1·2"가 찍힙니다.

7

제출합니다

모든 상품이 박스에 들어가면 제출 버튼이 켜집니다. 버튼 글자가 상황마다 다릅니다.

맞아요. 제출하고 다음 업체추천 그대로
이대로 제출하고 다음 업체 (박스 2개)직접 고쳤거나 추천이 없을 때
수정한 내용으로 다시 제출 (박스 2개)이미 제출한 업체를 고쳤을 때

버튼 아래 회색 글씨가 왜 안 눌리는지 알려 줍니다. 예) "아직 담지 않은 상품 1개", "박스를 추가해주세요".

라벨 출력 · 붙이기

제출한 업체의 화면 아래 송장 라벨 출력 영역에 박스마다 한 줄이 생깁니다. 제출 전에는 "박스 할당을 제출하면 라벨을 출력할 수 있습니다."라고 나옵니다.

1

미리보기를 확인합니다

왼쪽 그림이 실제로 찍힐 라벨입니다(고객명·터미널·바코드). 줄을 누르면 그 박스의 라벨로 바뀝니다. 그림 속 점선 "접는 선"이 박스 뚜껑 모서리에 닿는 자리입니다.

2

아이콘을 눌러 뽑습니다

출력 — 처음 뽑을 때. 상태 칩은 미출력
다시 출력 — 이미 뽑은 라벨을 한 번 더(구겨졌거나 잃어버렸을 때). 같은 바코드로 나옵니다.
재출력 필요 — 붙여 둔 라벨의 박스 종류가 지금과 달라졌습니다. 다시 뽑아서 바꿔 붙이세요.
출력 확인 중프린터 PC가 인쇄 완료를 확인하는 방식을 쓰는 경우에만 보입니다. 몇 초 뒤 "출력"으로 바뀝니다. 인쇄 창을 취소했거나 30분이 지나도 안 바뀌면 다시 출력하세요.

박스가 여러 개면 전체 출력 (3장) 으로 한 번에 뽑을 수 있습니다. 여러 업체를 한꺼번에 뽑으려면 맨 위의 라벨 일괄 출력 (2곳 · 5장) 을 누르세요(제출한 업체 중 안 뽑은 라벨만, 업체 번호 순서대로. 택배 업체는 제외).

3

붙입니다

인쇄 창이 뜨면 용지 크기가 라벨 크기와 같은지 보고 인쇄합니다. 나온 라벨의 점선을 박스 뚜껑 모서리에 맞춰 위쪽은 뚜껑 위에, 아래쪽은 옆면으로 꺾어 붙입니다. 라벨에는 박스 번호만 찍혀 있어서 박스 수가 늘어나도 이미 붙인 라벨은 그대로 둡니다.

라벨을 붙인 뒤에는 이것만 조심하세요
  • 가운데 박스를 빼면 뒤 박스 번호가 한 칸씩 앞당겨져 붙여 둔 스티커와 어긋납니다. 이때 "이미 라벨을 출력한 업체입니다…그래도 지울까요?" 확인창이 뜹니다. 정말 필요할 때만 "그래도"를 누르고, 번호가 바뀐 박스의 라벨은 다시 뽑아 바꿔 붙이세요.
  • 합포장을 바꾸거나 박스 종류를 바꾸면 "…옛 표시이니 다시 출력해서 바꿔 붙이세요" 노란 안내가 뜹니다.
  • 박스를 줄였을 때 남은 번호의 라벨은 붙이지 마세요(안내가 뜹니다).

팁

추천 탭을 누르면 새로 시작합니다
상품을 직접 옮긴 뒤 다른 순위 탭을 누르면 작성하던 내용이 사라집니다. 처음으로 돌리려면 추천대로 되돌리기.
자동으로 다시 나누기
고치다 꼬였으면 상품 자동으로 다시 나눠 담기 로 박스 칸을 새로 채웁니다(이 버튼은 고치는 중일 때만 보입니다).
주문 목록에서도 열립니다
주문 목록의 박스 칸(숫자)을 누르면 이 화면이 팝업으로 뜹니다. 제출하면 팝업이 닫힙니다.
"오늘 필요한 박스"
화면 위 줄에 박스 종류별 개수가 나옵니다. 박스를 준비할 때 보세요.

이럴 땐 이렇게

제출 버튼이 안 눌려요
버튼 아래 회색 글씨를 읽어 보세요. "아직 담지 않은 상품 N개"면 남은 상품을 담고, "N번 박스가 비어 있습니다"면 담거나 그 박스를 빼고, "삭제된 박스가 있습니다"면 그 박스를 지우고 다른 박스를 추가하세요.
"박스에 담을 수 없는 상품 N개가 목록에서 빠져 있습니다"라고 나와요
수량이 "미정"이거나 전량 미출고인 상품입니다. 박스에 담아야 한다면 주문 목록에서 수량이나 미출고를 먼저 고쳐 주세요.
노란 "주문 변경"이 떴어요
박스를 정한 뒤 주문이 바뀐 것입니다. 상품을 다시 확인하고, 필요하면 고쳐서 수정한 내용으로 다시 제출 하세요. 제출이 끝나면 칩이 사라집니다.
라벨 버튼이 안 보여요
제출 전이거나, 택배(별도 주문) 업체이거나, 라벨 출력 권한이 없는 계정입니다. 제출 후에도 안 보이면 관리자에게 알려 주세요.
라벨이 계속 "출력 확인 중"이에요
프린터 PC가 인쇄 완료를 알려 줘야 바뀝니다. 프린터가 꺼졌거나 인쇄 창을 취소했다면 30분 뒤 "미출력"으로 돌아가니 그때 다시 출력하세요. 계속되면 프린터 PC를 확인해 달라고 알려 주세요.

4상차 현황 — 터미널별·업체별 "실은 박스/전체 박스". 다 끝난 업체는 초록입니다.
5최근 스캔 — 눌러서 펼치면 최근 8건. 실패(빨강)·중복(갈색)이 구분되어 보입니다.

따라하기

1

날짜가 오늘인지 확인합니다

오늘이 아닌 날짜로 열면 노란 띠로 "○○ 날짜의 상차 현황입니다. 오늘 상차를 스캔하려면 오늘 날짜로 돌아가세요."라고 나옵니다. 그 화면에서는 오늘 박스를 상차할 수 없으니 오늘 화면으로 다시 들어오세요.

2

라벨을 읽습니다 — 카메라 또는 번호 입력

① 카메라
"스캔 시작하기"를 누르고 QR을 초록 네모에 맞춥니다. 같은 QR을 2.5초 안에 다시 읽는 것은 무시합니다. 카메라 권한이 막혀 있으면 주소창에서 허용해 주세요.
② 번호 입력
"라벨 번호 12자리 입력" 칸에 숫자 12자리를 쓰고 확인. 숫자 키패드가 나옵니다.
3

결과 색을 봅니다

결과마다 소리와 진동이 달라서 화면을 안 보고도 알 수 있습니다. 짧게 한 번 = 성공 · 두 번 = 이미 상차됨 · 길게 두 번 = 실패 (아이폰 사파리는 진동이 없습니다).

카메라가 켜져 있으면 결과 띠가 영상 아래에 2.4초만 나왔다 사라집니다. 방금 건을 확인하거나 되돌리려면 영상 바로 아래 "마지막 스캔" 줄을 보세요.

결과화면 문구어떻게 하나요
초록 성공"업체명 N번" · "합포장 1·2번 함께 상차" · 진행 N/M다음 박스를 읽습니다. 업체의 마지막 박스면 더 진한 초록으로 "이 업체 상차 완료"가 나옵니다.
노랑 중복"이미 상차된 박스" · "HH:MM에 처리됨"이미 실은 박스입니다. 다시 실었으면 그대로 두고, 잘못 기록된 것이면 아래 "취소"를 하세요.
빨강"출력된 적 없는 번호"형식은 맞지만 발급된 적 없는 번호입니다. 입력을 다시 확인하세요.
빨강"우리 라벨이 아닙니다" · "번호는 숫자 12자리입니다"다른 스티커이거나 자릿수가 틀렸습니다.
빨강"번호를 다시 확인해 주세요" · "확인 숫자가 맞지 않습니다"숫자를 잘못 읽거나 썼습니다. 다시 입력하세요.
빨강"M/D 날짜의 라벨입니다" · "오늘 박스가 아니라서 상차하지 않았습니다"어제 등 지난 날짜 스티커입니다. 박스 할당 화면에서 오늘 라벨을 다시 뽑아 붙이세요.
빨강"취소된 고객사의 박스입니다"라벨을 붙인 뒤 주문이 모두 취소된 업체입니다. 실지 마세요.
빨강"전송 실패 — 처리되지 않았습니다"신호가 불안정했습니다. 같은 라벨을 다시 비추면 바로 처리됩니다.
4

잘못 읽었을 때 — 취소

방금 스캔한 것 (초록)
배너의 잘못 스캔했어요 (되돌리기) 를 한 번 누르면 바로 취소됩니다. 카메라가 켜져 있으면 영상 아래 "마지막 스캔" 줄의 되돌리기.
이미 상차된 박스 (노랑)
상차를 취소할래요 를 누르면 4초 동안 정말 취소할까요? 한 번 더 누르세요 로 바뀝니다. 그때 한 번 더 눌러야 취소됩니다.

취소하면 노란 띠로 "업체 N번 상차를 취소했습니다. 이 박스는 다시 상차 전 상태입니다."가 나오고, 최근 스캔에 "(취소됨)"으로 남습니다. 되돌리기·취소 버튼은 권한이 있는 계정에만 보입니다.

5

합포장은 하나만 읽어도 전부

같이 묶어 둔 박스(합포장 1·2번)는 하나만 스캔해도 모두 상차 처리됩니다. 취소할 때도 묶음 전체가 같이 취소됩니다. "N번만 실었다"와 다르게 보일 수 있으니 결과 띠의 "합포장 1·2번 함께 상차"를 확인하세요.

6

끝나면 — 현황을 확인하고 카카오톡 글을 보냅니다

상차 현황에서 미완료 업체만(기본으로 켜져 있음)을 보면 아직 안 실은 업체가 남습니다. 라벨을 한 번도 뽑지 않은 업체는 이 화면에 나오지 않으니, 빠진 업체는 박스 할당에서 라벨을 뽑았는지 확인하세요.

상차 완료 글(카카오톡)은 상차 스캔 화면이 아니라 메뉴 "보내기" → "퀵기사" 탭에 있습니다.
터미널마다 카드가 있고, 아이콘 두 개로 보냅니다: 복사 · 카카오톡 보내기.
  • 보내기는 휴대폰에서만 켜집니다. 컴퓨터에서는 복사를 눌러 카톡에 붙여넣으세요(복사에 실패하면 글이 입력창에 나타나니 직접 복사).
  • 카드에 보냄 ✓ 10:42 가 남고, 보낸 뒤 상차가 더 되어 글이 바뀌면 보냄 10:42 이후 변경됨 으로 바뀝니다. 그때 다시 보내세요.
  • 글은 이렇게 나옵니다: "11/14(금) 대구 상차 완료 / 통영수산 2박스 / 합계 3박스 / 미상차: …" (일부만 실었으면 "3/5"처럼 표시되고 미상차 줄이 붙습니다).

이럴 땐 이렇게

카메라가 안 켜져요
브라우저 주소창의 카메라 아이콘에서 허용으로 바꾸세요. 그래도 안 되면 번호 입력으로 하세요(번호는 라벨에 인쇄되어 있습니다).
업체가 상차 현황에 안 나와요
그 업체의 라벨을 아직 한 번도 뽑지 않았거나(박스 할당 화면에서 확인), "미완료 업체만"이 켜져 있어 이미 끝난 업체가 가려진 것입니다.
라벨이 어제 날짜라고 나와요
어제 뽑은 스티커입니다. 오늘 라벨을 다시 뽑아 붙이세요(박스 할당 화면 → 라벨 출력).
스캔 버튼이 눌리지 않아요
상차 스캔 권한이 없는 계정입니다. 이때는 안내 글이 따로 뜨지 않으니 관리자에게 권한을 요청하세요.
