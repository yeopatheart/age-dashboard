# 진행 상황

마지막 갱신: 2026-11-16 (현장 개시 첫날 저녁, 세션 닫기)

## 된 것 (2026-11-16, 모두 main 머지)
- **기준 화면·줄에 붙는 필기** (#180): 모니터 1·2 줄 수를 기기와 무관하게 통일, 필기는 `row:업체카드id`로 줄에 저장. 칠판 펜 정상.
- **이름만 고친 경우 경고 없음**: 대시보드 "박스 재확인" (#181), 박스 할당 "주문 변경" 칩 (#191). 같은 기준(`isRenameOnly`).
- **주문 입력 마지막 입력 되돌리기** (#182, SQL 0066), "N건 안 보임" 오탐 수정 (#183).
- **화면 번호**: 일반 주문 1..N, 별도 주문 "별1, 별2…" (#184·#189·#185). 발급 번호(라벨·QR)는 그대로.
- **칠판 안정화**: 로그인 갱신 충돌(409)을 일시적 오류로 처리 (#188), 터치 기기는 배율 안 걸음 (#189), `board-env` 서버 로그 (#186).
- **별도 주문 팝업 무한 재렌더 수정 + 오류 화면 재시도 수정** (#190): 팝업에서 펜으로 포장 완료 시 "화면을 불러오지 못했습니다"가 뜨던 것. 칠판에서 해결 확인.
- **박스 할당 화면 정리** (#192): "박스 추가" 왼쪽 정렬, 모바일 칩 정렬.
- 기록: 점검표·프린터 결정·learnings (#187), CLAUDE.md 안티패턴 3건 (#193).

## 안 된 것 / 확인 대기
- **#191·#192·#193 배포 확인**: 머지 뒤 Vercel에서 파란 **Current**가 새 배포에 붙었는지(롤백 이후 자동 연결 설정 미확인) + 칠판·휴대폰 확인 결과 미수신.
- **번호 표시 현장 확인**: Promote 뒤 주문 목록 1번부터·별도 주문 "별N"이 보이는지 사용자 확인 대기.
- **#163 현장 안내서**: 열려 있음, 사용자가 배포 보류.
- **`board-env` 로그**: Promote 뒤 Vercel Logs에서 한 번도 확인하지 못함(칠판이 옛 배포였던 시간이 길었음). 처음 #184 직후 칠판 펜이 막힌 원인은 **끝내 미확인**(로그인 갱신 충돌 가설, 증명 못 함).
- **SQL 0066 운영 적용·실제 되돌리기 흐름**: 미확인.
- **라벨 프린터(4B-2054L)**: 드라이버 설치는 사용자가 처리 완료(2026-11-16). 감열 라벨지·시험 출력·스풀러(307 이벤트) 검증은 미확인 → `docs/decisions/2026-11-12-label-printer-and-label-stock.md`, `2026-11-14-label-print-spooler-confirm.md`.
- 이전 미처리 P2: A-13(포장 전용 권한), B-7(출력 후 변경 경고 일부는 #181·#191로 해소), C-4(미출고 → 판매가), C-11(모바일 정산 표). 주문 입력 ↔ 주문 목록 연동 1단계 미구현(`docs/decisions/2026-11-14-order-entry-sync-phase1.md`).
