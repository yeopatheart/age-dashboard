# 카카오톡 주문 메세지 포맷 가이드

**버전**: v1.0  
**작성일**: 2026-04-04  
**적용 대상**: 영업 담당자 (주문 메세지 작성 기준)

---

## 기본 구조

```
[번호] [터미널]/ [업체명]/ [상품1], [상품2], ...
```

### 예시
```
1 대구/ 스시아타이/ 활전갱이 3미, 일산중방어 1마리(5-6kg)
2 해운대/ 스시이루카/ 활전갱이 8마리, 일산참돔 2미, 양식광어 1미
3 남부/ 하시라/ 활전갱이 18미, 자연산 전복 4키로(300이상), 돌문어 4마리(2kg이상, 물봉 2박스), 벤자리 2미
```

---

## 구성 요소 설명

| 요소 | 설명 | 예시 |
|------|------|------|
| **번호** | 주문 순번 (1부터 시작) | `1`, `2`, `3` |
| **터미널** | 고속버스 터미널명 | `대구`, `해운대`, `남부`, `인천` 등 |
| **업체명** | 수신 업체명 | `스시아타이`, `신라호텔` |
| **상품** | 상품명 + 수량 + 단위 + (요청사항) | `활전갱이 3미`, `돌문어 4마리(물봉)` |

> ⚠️ 구분자는 반드시 `/` (슬래시)를 사용하고, 앞뒤 공백을 지켜주세요.

---

## 수량 단위 표준

| 단위 | 의미 | 표기 예시 |
|------|------|----------|
| `미` 또는 `마리` | 마리수 (개체 수) | `3미`, `5마리` |
| `키로` | 중량 (kg) | `2키로`, `1.5키로` |
| `팩` | 팩 단위 | `2팩` |
| `개` | 개 단위 | `10개` |

> ✅ `미`와 `마리`는 동일하게 인식됩니다. 편한 표기를 사용하세요.

---

## 핵심 규칙 2가지

### 규칙 1: 마리수 + 중량을 함께 기재할 때는 `+`로 구분

수량(마리수)과 중량을 함께 써야 할 경우, 반드시 `+`로 구분합니다.  
**순서는 항상 `수량(마리)` + `중량(키로)` 순으로 작성합니다.**

```
✅ 올바른 표기
감성돔 1미+2.5키로
대구 1마리+5.7키로
자연산 전복 6미+1키로

❌ 잘못된 표기 (파서 오류 발생)
감성돔 1미2.5키로
대구 1마리5.7키로
자연산 전복 1키로6미
```

---

### 규칙 2: 포장 특이사항은 항상 맨 끝 괄호에 기재

상품 스펙(크기/중량 요구)과 포장 방식은 **상품명 뒤 마지막 괄호 하나**에 `,`로 구분해서 함께 작성합니다.

```
✅ 올바른 표기
돌문어 4마리(2kg이상, 물봉)
돌문어 4마리(2kg이상, 물봉 2박스)
왕우럭조개 3미(작은것, 물봉)
활장어 2키로(키로5-6미급, 기포기)
자연산 전복 6미+1키로(얼음포장)
자연산 전복 4키로(300이상)

❌ 잘못된 표기 (파서 오류 발생)
돌문어(2kg이상) 4마리(물봉 2박스)   ← 괄호가 2개
왕우럭조개 3미(작은 물봉)            ← 물봉이 괄호 안에 묻힘
활장어(키로 2미) 2키로(기포기)       ← 괄호가 2개
```

## 포장 키워드 목록

괄호 안에 아래 키워드가 포함되면 시스템이 자동으로 인식합니다.

| 키워드 | 시스템 처리 | 설명 |
|--------|------------|------|
| `물봉` | 물봉박스 배정 | 생물 + 산소기 밀봉 포장 |
| `물봉 [N]박스` | 물봉박스 N개 배정 | 박스 수량 지정 물봉 |
| `기포기` | 물봉박스 배정 | 산소 공급 장치 포함 포장 |
| `얼음포장` | 특이사항 메모 | 일반박스 + 얼음포장 처리 |
| `재고` | 재고 출고 표시 | 창고 재고에서 처리 |
| 그 외 내용 | 크기/중량 요청사항으로 저장 | 예: `2kg이상`, `큰거`, `작은것`, `300이상` |

## 자주 하는 실수 체크리스트

- [ ] 구분자 `/` 앞뒤에 공백이 있는가? (`대구/ 스시아타이/` ✅, `대구/스시아타이/` ❌)
- [ ] 수량+중량 병기 시 `+`로 구분했는가? (`1미+2.5키로` ✅)
- [ ] 포장 특이사항(물봉, 기포기 등)이 맨 마지막 괄호 안에 있는가?
- [ ] 괄호가 상품 하나에 2개 이상 사용되지 않았는가?
- [ ] 상품 간 구분자가 `,`(쉼표)인가?
