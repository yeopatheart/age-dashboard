# 카카오톡 주문 메시지 작성 가이드

**버전**: v2.0 · **적용 대상**: 주문 메시지를 작성하는 사람(대표) · **개정일**: 2026-10-08

이 가이드대로 쓰면 대시보드에 **오류 없이 한 번에** 반영됩니다. 조금 다르게 써도 시스템이 최대한 읽어주지만, 읽지 못한 줄은 확정 전에 걸러져 다시 써야 합니다.

---

## 1. 한 줄 구조

```
번호 터미널/ 업체명/ 상품, 상품, 상품
```

```
1 대구/ 엔야/ 활전갱이 5미, 활고등어 5미, 양식광어 1미
17 남부/ 신라호텔/ 활전갱이 1키로, 전복 2마리(300이상, 물봉)
```

| 항목 | 규칙 |
|---|---|
| 번호 | 생략해도 됩니다. 번호는 시스템이 따로 관리합니다. |
| 터미널 | 대구, 남부, 해운대 등. 처음 쓰는 이름이면 자동으로 새 터미널로 등록됩니다. |
| 업체명 | 처음 쓰는 업체는 자동으로 등록됩니다. 비슷한 이름은 기존 업체로 연결됩니다. |
| 구분자 | 반드시 `/`. 앞뒤 공백은 있어도 없어도 됩니다. |
| 줄바꿈 | 업체 한 곳당 한 줄입니다. 줄 사이 빈 줄은 얼마든지 괜찮습니다. |
| 날짜 줄 | `9/29(화)` 같은 날짜 줄은 읽고 무시합니다. |

---

## 2. 상품과 수량

`상품명 수량단위` 형식이고, 상품은 `,`로 구분합니다. **수량은 반드시 있어야 합니다.**

| 단위 | 의미 | 예시 |
|---|---|---|
| `미` 또는 `마리` | 마릿수 (같은 뜻) | `3미`, `5마리` |
| `kg` 또는 `키로` | 무게 (화면에는 kg으로 표시) | `2kg`, `1.5키로` |
| `g` | 자동으로 kg으로 환산 | `500g` → `0.5kg` |
| `팩` | 팩 | `2팩` |
| `개` | 개 | `12개` |

### 마릿수 + 무게를 함께 쓸 때는 `+`

순서는 **마릿수 먼저, 무게 나중**입니다.

```
✅ 감성돔 1미+2.5kg
❌ 감성돔 1미2.5kg      (+ 없음)
❌ 감성돔 2.5kg+1미     (순서 바뀜)
```

---

## 3. 괄호 — 상품당 하나, 맨 끝

사이즈 요청과 포장 방식은 **상품 맨 끝 괄호 하나**에 `,`로 모아 씁니다.

```
✅ 전복 2마리(300이상, 물봉)
✅ 돌문어 3마리(2kg이상, 기포기)
✅ 활장어 2kg(3미급)
✅ 보리새우 50미(선별, 물봉 2박스)
```

| 괄호 안 키워드 | 의미 |
|---|---|
| `물봉`, `기포기` | 물봉 박스로 포장 |
| `물봉 2박스` | 물봉 박스 개수 지정 |
| `얼음포장` | 얼음 포장 |
| `재고` | 창고 재고에서 출고 |
| 그 외 (`큰거`, `300이상`, `2kg이상` 등) | 사이즈 요청으로 저장 |

> 💡 괄호를 `전복(300이상) 2마리(물봉)`처럼 앞뒤로 나눠 써도 시스템이 위 표준 형식으로 **자동 정리**합니다. 확인 화면에 "표준 형식으로 정리됨"이라고 표시되니, 정리된 결과만 확인해 주세요. 그래도 처음부터 표준 형식으로 쓰는 편이 안전합니다.

---

## 4. 메모 — 줄 끝에 `#`

포장 담당자에게 전할 말은 줄 맨 끝에 `#`을 붙여 씁니다. 메모 안에는 어떤 글자를 써도 됩니다.

```
44 대전/ 키혼/ 일산참돔 1미(작은거), 벤자리 2미 #이자카야 소리처럼 작업하기
```

- 메모는 대시보드 해당 업체 줄의 **빈 칸**에 노란색 글씨로 보입니다.
- 같은 업체에 새 메모를 보내면 이전 메모를 **덮어씁니다**.
- ❌ `벤자리 2미 - 이자카야 소리처럼 작업하기` 처럼 `-`로 이어 쓰면 상품 이름으로 읽혀 오류가 납니다.

---

## 5. 취소

| 하고 싶은 것 | 쓰는 법 |
|---|---|
| 상품 하나 취소 | 같은 업체 줄에 `상품명 취소` — 예: `46 수원/ 스시태양/ 갯가재 취소` |
| 업체 주문 전체 취소 | `터미널/ 업체명/ 취소` — 예: `46 수원/ 스시태양/ 취소` |

- 취소된 상품은 대시보드에 **취소선**으로 남습니다(기록 유지).
- 오늘 주문에 없는 상품을 취소하려 하면 확정이 막힙니다. 상품명을 확인해 주세요.

---

## 6. 하루 중 추가·수정할 때

- **바뀐 줄만** 다시 보내면 됩니다. 이미 등록된 상품은 상품명이 같으면 같은 상품으로 봅니다.
- 수량, 무게, 괄호 내용이 **하나라도 다르면** `기존 상품 수정`, **전부 같으면** `변경 없음`으로 표시되고 반영되지 않습니다.
- 새 상품은 `추가`로 표시됩니다.
- 상품명은 표기를 통일해 주세요. `활고등어`와 `활 고등어`는 다른 상품으로 보입니다.

---

## 7. 확인 화면 읽는 법

분석 버튼을 누르면 한 줄씩 결과가 나옵니다.

| 표시 | 의미 |
|---|---|
| 초록 `추가` | 오늘 처음 들어오는 상품 |
| 노랑 `기존 상품 수정` | 이미 있는 상품의 내용이 바뀜 |
| 회색 `변경 없음` | 이미 있는 내용과 완전히 같음 (반영 안 됨) |
| 빨강 `취소` | 기존 상품을 취소함 |
| 파랑 `신규 터미널` / `신규 업체` | 확정하면 자동으로 새로 등록됨 |
| ⚠ `확인 필요` | 읽긴 했지만 사람이 한 번 봐야 함 (확정은 가능) |
| `수정 필요` | **수량 없음 등으로 확정 불가** — 카톡 메시지를 고쳐서 다시 분석 |

`확인 필요만 보기` 버튼으로 문제가 있는 줄만 모아 볼 수 있습니다.

## 8. 자주 하는 실수

| ❌ 이렇게 쓰면 | ✅ 이렇게 | 이유 |
|---|---|---|
| `금태` | `금태 1미` | 수량이 없으면 확정이 막힙니다 |
| `벤자리 2미 - 소리처럼` | `벤자리 2미 #소리처럼` | 메모는 `#` |
| `활장어(키로 3미) 2키로` | `활장어 2kg(3미급)` | 괄호는 맨 끝 하나 (자동 정리는 됨) |
| `감성돔 1미2.5kg` | `감성돔 1미+2.5kg` | 마릿수와 무게는 `+` |
| `남부 해운대/ 스시…` | `남부/ 스시…` | 슬래시는 정확히 2개 |
