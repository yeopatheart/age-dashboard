# 2026-11-17 PC에서 필기가 가로·세로로 어긋나는 캔버스 해상도 불일치를 고친다

## 맥락
PC에서 필기가 쓴 자리에서 가로·세로로 같은 비율만큼 밀려 보이는 일이 있었다(캔버스 왼쪽 위 원점에서 커지거나 작아진 모양). 새로고침하면 제자리로 돌아온다. 칠판에서는 나타나지 않았다.

## 원인
- 필기 캔버스는 `fitCanvas`(`src/lib/ink/canvas.ts`)로 그림 해상도(`canvas.width/height`)와 변환을 **그때의 rect 크기**에 맞춘다. 이 함수는 `ResizeObserver(canvas)`가 발동할 때만 다시 불렸다.
- PC는 기준 화면(`BoardStage`, 1248×696 고정)에 CSS `transform: scale`을 걸어 확대·축소한다. `ResizeObserver`의 content-box는 배율 전 크기라서 **배율만 바뀌면 발동하지 않는다**(사이드바 접고 펴기, 창 크기·브라우저 확대 변경, 하이드레이션 뒤 저장된 사이드바 값 반영, 폭 전환 등).
- 그런데 `redraw`(`ink-layer.tsx`)는 매번 새 `getBoundingClientRect` 기준으로 점을 계산해 그린다. 그래서 배율이 바뀐 뒤에는 **옛 해상도 버퍼에 새 좌표로** 그려져, 화면에 k = 새 rect / 옛 rect 배의 위치·크기로 나온다.
- 저장된 필기 데이터(`pts`·`lay`·앵커)는 틀리지 않았다. 그리는 쪽의 버퍼만 틀렸다.
- 칠판은 배율이 항상 1(native)이고 캔버스 크기가 바뀔 때마다 `ResizeObserver`가 발동해 정상이다.

## 결정
- `redraw` 맨 앞에서, 이미 읽는 `getBoundingClientRect` 값으로 버퍼가 맞는지 확인하고(`needsFit(bufW, bufH, rectW, rectH, dpr)`, 순수 함수, 테스트 `src/lib/ink-canvas-fit.test.ts`) 다르면 `fitCanvas`를 다시 부른 뒤 그린다.
  - 맞는 기준은 `backingSize(rect, dpr)`와 `canvas.width/height`의 차이가 가로·세로 모두 ±1px 이내. 소수점 반올림 때문에 매번 다시 잡지 않는다.
  - rect가 0·NaN이면 판단하지 않는다(다시 잡지 않는다).
  - 칠판(배율 1)은 rect와 버퍼가 이미 맞아 이 확인이 항상 false라 동작이 달라지지 않는다.
  - rect 읽기는 `redraw`가 원래 하던 것을 그대로 쓴다(읽기를 늘리지 않는다). 다시 잡을 때만 `canvas.width` 쓰기가 일어난다.
  - 무한 호출 없음: `fitCanvas`는 버퍼 크기만 바꾸고 CSS 크기(`h-full w-full`)는 그대로라 `ResizeObserver`가 다시 발동하지 않는다. 발동하더라도 다음 `redraw`에서 `needsFit`이 false여서 멈춘다.
- 배율이 바뀔 때도 다시 그리도록 `InkLayer`에 선택 prop `scale`을 받아 `redraw` 의존성에 넣었다. `dashboard-client.tsx`는 PC 읽기 전용 `InkLayer` 한 곳에 `scale={stage.scale}`만 전달한다. 이 prop이 없어도(옛 버퍼가 CSS로 늘어나 흐릿하지만 줄과 같이 움직여 위치는 맞다) 위치 결함은 `redraw` 안의 확인으로 막히며, 배율 변화에 맞춘 다시 그리기는 선명도를 위한 것이다. 다시 그리는 횟수는 배율이 바뀔 때만 늘어난다.
- 칠판 필기 입력·판정, 저장 형식, `lay`·`pts` 의미, 줄 수·줄 높이 규칙, 레이아웃은 건드리지 않는다.

## 한계
- **칠판 확인 필요.** 칠판은 배율 1이라 이 변경이 동작을 바꾸지 않아야 하지만(`needsFit` false), 칠판에서 직접 확인하지 못했다.
- 이미 어긋나 보이는 PC 화면은 새로고침해야 한다(옛 코드가 돌고 있는 화면이다). 저장된 필기 데이터는 틀리지 않았으므로 새 코드가 배포된 뒤 새로고침하면 제자리로 보인다.
- PC에서 사이드바 토글·창 크기 변경 뒤의 실제 필기 위치는 화면에서 확인하지 못했다.
- 별도 주문 팝업의 `InkLayer`는 배율 안에 있지 않아 `scale`을 넘기지 않는다(redraw 안의 확인은 같이 적용된다).

## 확인 방법 (배포 뒤)
1. PC에서 필기가 있는 날짜의 주문 목록을 연다. 사이드바를 접고 펴 본다. 필기가 줄·칸 위에 그대로 있는지, 흐려지지 않고 선명한지 본다.
2. 창 크기를 바꾸고, 브라우저 확대(Ctrl +/−)를 바꿔 본다. 새로고침 없이 필기가 줄을 따라가야 한다.
3. 칠판에서 `/dashboard/pen-test`와 주문 목록이 정상(까만 화면 아님)인지, 쓰기·지우기·사이드바 펼침이 이전과 같은지 본다. 어느 배포(파란 Current)를 본 것인지도 함께 확인한다.
4. 롤백은 안전하다(저장 형식 변경 없음).
