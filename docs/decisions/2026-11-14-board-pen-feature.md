# 칠판 펜 기능 (2026-11-14 확정, 구현 완료 — 칠판 시험 대기)

> 구현 위치: `src/lib/ink/*`(순수 함수: `gesture`, `erase`, `history`, `store`, `radial`, `canvas`), `src/app/(dashboard)/dashboard/ink-layer.tsx`(그림 층·플로팅 버튼·도구함), `dashboard-client.tsx`(칠판 버튼·연결), `dashboard-sound.tsx`(알림 항상 ON·이력 전용). 기준값은 `gesture.ts`의 `GESTURE`, 손바닥 기준은 `ink-layer.tsx`의 `PALM_PX`(24)에 모여 있다.
> 칠판 시험 방법: 주소에 `&ink=dry`를 붙여 열고 '칠판' 버튼 → 오른쪽 아래 펜 버튼 → 펜 → 상품에 동그라미/대각선. 인식 결과와 감싼 비율이 화면에 뜨고 포장 상태는 바뀌지 않는다. 기준이 맞으면 `&ink=dry`를 빼고 쓴다.
> 알림이 항상 ON이 되면서 화면 절전 방지(wake lock)도 PC 화면에서 항상 켜진다.

배경: 스마트 칠판(CSS 1280×720, devicePixelRatio 3)에서 작업자가 상품에 동그라미 또는 대각선을 그리면 그 상품을 **포장 완료**로 올린다. 진단 결과와 근거는 `2026-11-14-tv-board-optimization.md`. 모든 항목은 사용자가 확정했다.

## 확정한 설계
### 상단 툴바(칠판 켜기)
- 칠판(보기 전용) 스위치를 알림 패널에서 빼서 **상단 툴바에 고정**한다. **'칠판' 버튼 하나**(칠판 모양 아이콘 + "칠판" 글자, 켜면 남색 채움). 강조 상품 버튼(형광펜 아이콘, 빨강, 개수)과 구분한다.
- '칠판'을 켜면 **보기 전용** + **펜 플로팅 버튼 표시**. 끄면 평소 화면. 플로팅 버튼은 이 버튼으로만 ON/OFF하고 **자동으로 닫히는 기능은 없다**.
- 알림은 **항상 ON**. 알림 패널의 켜기·끄기·소리 스위치와 "실시간 알림 켜기"를 없앤다. 알림 버튼을 누르면 **최근 변경 이력(+ 모두 확인)만** 나온다. 패널 하단에 "소리·알림 설정" 작은 링크는 남긴다. 벨 색(정상/연결 끊김)과 브라우저가 소리를 막았을 때의 "소리 켜기" 버튼은 유지(브라우저 정책). 창 하나만 조용히 하는 `&sound=off`는 유지.

### 플로팅 버튼과 도구함
- 지름 56px 이상, 드래그로 이동하고 위치를 기기에 저장. 눌러서 펼치면 **버튼 둘레에 사방으로** 도구가 펼쳐진다(화면 가장자리 근처면 빈 쪽으로 부채꼴).
- 도구: 펜, 지우개, 되돌리기. 펜은 색 5가지(빨강·파랑·검정·초록·주황), **굵기는 드래그로 조절**(1~24px, 기본 4, 미리보기 원). 지우개는 **크기를 드래그로 조절**(8~120px, 기본 40, 미리보기 원). 마지막 값은 기기에 저장.
- 지우개를 고른 상태에서 지우개 버튼을 **1초 누르고 있으면 전체 지우기**(진행 링, 중간에 떼면 취소). 전체 지우기도 되돌리기로 복구된다.
- 도구를 고른 동안만 그려지고, 같은 도구를 다시 누르면 터치가 통과한다.
- **모니터 1·2에서만** 사용(전체보기는 스크롤로 그림이 어긋나서 제외). 노출 조건: 칠판 켬 + 수정 권한 + 오늘(또는 과거 편집 허용).

### 입력 처리
- 펜·손가락·지우개가 모두 `touch`라 도구 선택으로 구분한다.
- **손바닥**: 접촉 폭·높이가 24px을 넘으면 무시(진단: 손가락·펜 1×1, 손바닥 52×62). 손바닥이 먼저 닿아 있어도 작은 접촉은 그린다. 한 획이 진행 중일 때 들어오는 다른 작은 접촉은 무시.
- 선은 `src/lib/ink/canvas.ts`(해상도 × devicePixelRatio, 곡선 보정)로 그린다.

### 인식 → 포장 완료
- **동그라미**: 닫힌 곡선이 **상품 칸 면적의 40% 이상**을 감싸면 인정. 40%로 낮춘 대신 가장 많이 감싼 칸이 두 번째 칸보다 **15%p 이상 앞설 때만** 처리하고 애매하면 무시한다.
- **대각선**: 거의 직선이고 칸을 대각으로 가로지를 때. 기준은 칠판에서 맞춘다.
- 이미 포장 완료인 상품, 취소된 상품, 두 칸에 걸친 경우는 무시(그림만 남음). 해제는 하지 않는다. 화면에는 표시 없이 뒤에서 처리하고 상품 칸이 포장 완료 색으로 바뀌는 것이 성공 표시. 중량은 인식하지 않는다.
- 서버: 기존 `togglePacked(상품 id, true)`(권한·날짜 확인 포함)를 쓴다. 새 서버 기능·마이그레이션 없음.
- **시험 모드** `&ink=dry`: 인식 결과(종류, 어느 상품, 감싼 비율, 안 된 사유)를 칠판 화면에 바로 보여 주고 포장 상태는 바꾸지 않는다. 시험 결과를 붙여 넣을 필요는 없고, 기준 조정이 필요할 때만 알려 주면 된다.

### 그림 저장과 되돌리기
- 인식된 원·대각선은 **해당 상품 칸에 붙인다**(획 좌표를 칸 크기 비율로 저장 → 칸이 움직여도 따라감). 그 외 낙서는 화면 크기 비율로 저장. 칸이 화면에 없으면 그리지 않고 보관.
- 날짜·모니터별로 이 기기(localStorage)에 저장, 새로고침해도 유지. 점 줄이기, 개수 상한, 오래된 날짜 자동 삭제. 저장이 막히면 화면에서만 유지.
- 다른 기기에서 포장 해제해도 칠판의 원 그림은 **그대로 유지**.
- **되돌리기** = 직전 펜 작업을 지우고 이전 단계로 돌아감. 포장 완료로 올린 원을 되돌리면 그 상품의 포장 완료도 취소(이미 다른 곳에서 해제됐으면 건드리지 않음). 최근 30단계, 메모리에만 있음(새로고침하면 사라짐).
- **지우개·전체 지우기는 그림만 지우고 포장 상태는 유지**(실수로 하루치 포장 상태가 풀리는 사고 방지).

## 확인하지 못하는 것(칠판에서 확인)
인식 기준값(감싸는 비율, 직선도, 각도), 손바닥 기준(24px), 유령 터치, 젖은 손 입력, 실제 칠판에서의 선명도.

## 칠판 시험 후 변경 (2026-11-14, 같은 날 현장 요청)
- **'칠판' 버튼에서 글자를 뺐다.** 칠판 모양 아이콘만 두고, 켜지면 남색으로 채워 강조 상품 버튼(형광펜)과 구분한다.
- **플로팅 버튼 조작을 바꿨다.** 짧게 누르면 **펜 켜기/끄기**(켜면 이전에 정한 색·굵기를 그대로 쓴다), **길게 누르면(0.5초) 메뉴**(펜 설정·지우개·되돌리기)가 사방으로 펼쳐지고, 끌면 위치를 옮긴다. 색·굵기·지우개 크기는 한 번 정하면 계속 쓰므로 설정 카드가 계속 떠 있지 않다 — **펜 설정이나 지우개를 눌렀을 때만 카드가 뜨고, 그리기 시작하면 메뉴와 카드가 닫힌다.** 메뉴가 열려 있을 때 버튼을 짧게 누르면 메뉴만 닫는다. 지우개를 고른 뒤 1초 누르면 전체 지우기는 그대로.
- **동그라미 인식 규칙 변경.** 칠판 시험에서 큰 원을 쳐도 인식되지 않았다. 원인: 칸이 위아래로 촘촘해서 큰 원이 옆줄 칸도 40% 이상 감싸는데, 예전 규칙(가장 많이 감싼 칸이 두 번째 칸보다 15%p 앞서야 함)이 이를 "애매함"으로 무시했다. 이제 40% 이상 감싼 칸 중 **원의 중심에 가장 가까운 칸**을 고르고(칸 크기로 나눈 거리), 1등과 2등의 거리 차가 0.3보다 작을 때(원의 중심이 두 칸의 한가운데)만 애매하다고 무시한다. 칸의 40~50%만 감싼 원도 인식된다.
- **대각선 → 직선(방향 무관)으로 변경.** 예전 규칙이 각도(15~75°)와 세로 가로지름을 요구해 가로선·세로선을 모두 거절했다. 이제 거의 곧은 획(시작-끝 거리/획 길이 ≥ 0.85)이 **칸의 50% 이상을 그 방향으로 가로지르면** 방향과 상관없이 포장 완료로 올린다(칸을 가로지르는 길이는 선 방향으로 칸의 중심을 지나는 현의 길이로 잰다: 가로선이면 칸 폭, 세로선이면 높이). 획 길이의 50% 이상이 칸 안에 있어야 하고, 두 칸이 비슷하게 걸치면 무시한다. 최소 획 길이는 40 → 24px, 최소 점 수는 4 → 3으로 낮췄다.
- 알려진 한계: 칸 사이 간격이 2~4px뿐이라, 칸 바로 아래에 그은 밑줄은 **아래 칸 위의 직선**으로 판정될 수 있다. 칸 안에서 여러 번 꺾이는 지그재그 한 획은 직선으로 보지 않는다.

## 칠판 시험 후 변경 2 (2026-11-14, 같은 날 현장 요청)
- **지우개로 지우면 포장 완료도 원복한다.** 현장에서는 바로 전에 한 것이 아니라 **이전에 포장 완료로 올린 것**을 취소하는 경우가 있어서, 되돌리기뿐 아니라 지우개로도 풀 수 있어야 한다. 지우개가 닿아 잘라 낸 획이 **포장 완료로 올릴 때 붙은 동그라미·직선**이면(예전에 한 것, 새로고침 전에 한 것 포함) 그 상품의 포장 완료를 해제한다(이미 해제됐거나 취소된 상품은 건드리지 않음). 한 번 지우는 동작(손가락을 떼기까지)에서 닿은 상품들을 모아 한 번에 해제한다. 되돌리기로 그 지우기를 복구하면 그림과 함께 그 상품들을 다시 포장 완료로 올린다(그 사이 다른 곳에서 이미 바뀌었으면 건드리지 않음). 시험 모드(`&ink=dry`)에서는 "포장 해제 대상: 업체 상품"만 보여 주고 바꾸지 않는다. 이 변경으로 앞의 "지우개는 그림만 지우고 포장 상태는 유지" 결정을 지우개에 한해 바꿨다.
- **전체 지우기는 그대로 그림만 지운다**(포장 상태 유지). 하루치 포장 상태가 한꺼번에 풀리는 사고를 막으려는 앞의 결정을 유지했다. 전체 지우기도 포장 해제까지 하길 원하면 알려 달라.
- **기본 지우개 크기를 반지름 40 → 16px로 줄였다.** 지우개가 닿으면 포장도 풀리므로, 위아래로 촘촘한 칸(약 30px)에서 이웃 칸의 동그라미까지 닿지 않게 한다. 이미 정한 값이 있는 기기는 그대로이고 크기 카드에서 바꿀 수 있다.
- **메뉴를 세로 목록으로 되돌렸다.** 사방으로 펼치던 방식은 목록을 많이 가려서, 플로팅 버튼 **위(화면 아래쪽에 있을 때) 또는 아래**로 펜 설정·지우개·되돌리기를 한 줄로 쌓는다. 설정 카드는 버튼 열 옆(버튼이 오른쪽이면 왼쪽)에 뜬다. 짧게 누르면 펜 켜기/끄기, 길게 누르면 메뉴, 끌면 이동은 그대로.

## 칠판 시험 후 변경 3 (펜 충실도 · 행 맞춤 · 품목 칩 · 연결 경고)

- **펜이 쓴 그대로 보이게**: 이전 렌더링은 점을 근사 곡선(평활)으로 그려서 글씨 모양이 바뀌었고, 저장·재그리기 때도 한 번 더 뭉개졌다. 이제 샘플한 **모든 점을 지나는** 베지어 곡선(핸들 = 구간 길이/3, 접선 = 이웃 점 방향, 55° 넘게 꺾이는 모서리는 그대로 각지게)으로 그리고, 그리는 중과 확정 뒤(`drawPath`)가 같은 함수라 모양이 변하지 않는다. 점은 1.5px 이상 움직였을 때만 저장하고 획 끝점을 항상 넣는다(MAX_POINTS 800).
- **모니터 1 하단 여백**: `fitRowHeight`(src/lib/row-fit.ts)가 남는 높이가 어중간하면 행 높이를 최대 6px(최소 30px) 줄여 한 행을 더 넣는다. 줄여도 최소 높이 미만이 되면 그대로 둔다.
- **품목별 수량 칩**: 추가(+N)·미정 배지가 칩 테두리에 닿아(15px 칩에서 틈 0.3px) 깨져 보였다. 배지를 칩 글자의 0.9배 · 위아래 1px 여백 · `leading-none`으로 줄여 틈 1.3~2.3px을 확보했다.
- **상품 칩 → 고객사 목록**: 칩(모니터 2 패널 · 전체보기 · 별도 주문 팝업)을 누르면 플로팅 카드(`product-customers-popover.tsx`)에 이 상품을 주문한 고객사와 수량(미출고·수량 미정·포장 ✓)을 보여 준다. 고객명은 말줄임 없이 줄바꿈. 위치는 순수 함수 `placePopover`(화면 밖으로 안 나가게). 바깥 클릭·Esc·✕로 닫는다. 목록은 mobile과 같은 `getProductCustomers`로 계산한다.
- **"연결이 끊겼습니다" 경고**: 알림이 항상 ON이어도 실시간 연결은 네트워크·절전으로 끊길 수 있다(오히려 모든 PC가 연결해서 더 보일 수 있음). 끊김 8초 유예 뒤에만 경고·소리를 내고, 연결이 죽어 있으면 10초마다 자동 재연결한다.

## 칠판 시험 후 변경 4 (칠판 버튼 제거 · 고객명 패널 · 버튼 축소)

- **칠판 버튼 제거**: 상단 "칠판" 스위치(`board-view-only`)를 없앴다. 플로팅 펜 버튼을 켠 동안이 칠판 모드(카드 탭 막힘)이고 끄면 일반 모드다. 작업자가 거치는 단계가 하나 줄었다.
- **펜 버튼을 보이는 기기**: 스위치가 없어졌으므로 "터치 입력이 있는 데스크톱 화면"(`src/lib/touch-device.ts`: maxTouchPoints ≥ 1, 폭 > 768, 휴대폰·태블릿 UA 아님)에만 보인다. 칠판만 콕 집어 식별할 방법이 없어서(진단: Linux Chrome, 터치 2점, 1280×720) 터치 노트북 같은 기기에도 보일 수 있다. 판별이 틀리면 주소에 `&pen=1`(강제 표시) / `&pen=0`(숨김)을 붙인다. 서버 렌더는 항상 숨김이다(펜 층이 렌더 중 `window`를 읽는다).
- **플로팅 버튼 80%**: 56px → 45px(메뉴 버튼·아이콘·간격도 같은 비율). "펜 설정"을 다시 누르면 설정 카드가 닫힌다(펜은 켜 둔 채).
- **터미널 열 폭**: 80px 고정 → 그날 가장 긴 터미널 이름 칩에 맞춤(최소 56px, 최대 120px). 수정·삭제 버튼 자리가 필요 없어졌다.
- **상품 칸은 포장 완료만**: 상품 칸의 호버 버튼(수정·미출고·취소·삭제)과 터미널 칸의 주문 수정·삭제 버튼을 뺐다. 대신 **고객명을 누르면** 그 옆에 패널(`customer-order-panel.tsx`)이 떠서 상품 추가·주문 수정·주문 삭제와 상품별 수정·미출고·취소·삭제를 한다. 기존 모달과 핸들러를 그대로 쓴다(모달을 여는 동작은 패널을 닫고 연다, 취소는 패널을 열어 둔 채 실행해 결과를 바로 보여 준다). 펜이 켜져 있는 동안·과거 날짜·수정 권한 없음이면 고객명이 눌리지 않는다. 별도 주문 팝업은 이번에 건드리지 않았다.

## 칠판 시험 후 변경 5 (펜 그림을 서버에 저장해 PC에서도 보기)

- **요구**: 형이 PC에서도 칠판에 쓴 펜 그림을 보고 싶다. PC에서 쓰는 기능은 필요 없고 보기만, 모니터 1·2 각각.
- **저장**: 마이그레이션 0057 `board_ink`(날짜·모니터당 한 행, `strokes` jsonb에 획 전체). 칠판이 그리거나 지울 때마다 0.5초 단위로 묶어 서버 액션 `saveBoardInk`로 통째로 덮어쓴다. 보기=`dashboard:view`, 쓰기=`dashboard:edit`. 서버가 유일한 원본이고(예전 localStorage 그림 저장은 삭제), 펜 설정·버튼 위치만 기기별 로컬이다. 보관 3일(오늘·어제·그제): 저장할 때 그보다 오래된 행을 지운다. 시험 모드(`&ink=dry`)는 서버에 저장하지 않는다.
- **PC 보기**: 펜을 못 쓰는 기기는 같은 그림 층을 읽기 전용(`viewOnly`)으로 겹쳐 본다. 캔버스는 입력을 통과시킨다. 툴바에 보기/숨기기 버튼(기기별 저장 `board-ink-hidden`, 기본은 보임). 전체보기는 제외.
- **갱신**: `board_ink` 전용 Realtime 채널(주문 알림 채널과 분리 — 마이그레이션 전에 배포돼도 주문 알림이 영향받지 않게)이 변경 신호를 주면 그 한 행만 다시 읽는다. 신호를 놓쳐도 보이는 동안 15초마다·탭 복귀·인터넷 복구 때 다시 읽는다.
- **저장 실패**: 칠판 화면에 "그림이 저장되지 않았습니다 — 눌러서 다시 시도"가 뜨고 다음 변경 때도 다시 보낸다. 테이블이 없으면 필요한 마이그레이션을 안내한다.
- **한계**: 상품 칸에 붙은 동그라미·직선은 칸을 따라가 PC에서도 같은 자리지만, 칸에 안 붙은 자유 필기는 화면 폭·비율이 다르면 위치가 조금 어긋난다. 칠판이 둘 이상 동시에 쓰면 마지막 저장이 남는다(동시 쓰기 병합 없음).
- **확인**: 칠판에서 저장 → 새로 연 PC 화면에서 같은 그림이 그려짐, 칠판 재로드 시 서버 그림 복원, 전체 지우기 저장을 확인했다. 실시간 푸시로 즉시 갱신되는 것은 두 화면을 동시에 띄운 환경에서 보지 못했다(15초 재조회가 안전망).
- **SSR 주의**: 그림 층은 렌더 중 `window`를 읽으므로 서버에서 그리면 오류가 난다. 펜 노출·PC 보기 모두 하이드레이션 뒤(`useHydrated`·`useTouchDesktop`)에만 그린다.

## 칠판 시험 후 변경 6 (주문 목록 개선 1: 박스 열 · 지우개 복귀 · 품목 팝업 편집 · 소리 지연 · 펜 속도)

- **박스 열**: 88px → 64px 고정. 박스 수(최대 두 자리) + 재확인 경고 아이콘 + 합포장 배지 "합"(전체 이름은 툴팁)이 한 줄에 들어가는 최소 폭이다.
- **지우개 복귀**: 지우개를 선택한 뒤 지우개 버튼을 다시 누르거나 플로팅 버튼을 누르면 펜이 켜진 상태로 돌아온다(예전에는 펜이 꺼져 한 번 더 눌러야 했다). 펜을 끄려면 펜 상태에서 플로팅 버튼을 누른다.
- **품목별 수량 팝업 편집**: 팝업의 고객 줄을 누르면 그 고객의 이 품목 포장 완료가 켜지고 꺼진다(주문 목록 상품 칸과 같은 `togglePacked`, 낙관적 반영). 줄이 하나뿐인 고객은 수량을 −/+(0.6초 모아 한 번 저장) 또는 숫자 직접 입력으로 고친다 — 주문 수정과 같은 `updateOrderItemManual`이라 수정 표시·미출고 수량 보정이 같다. 같은 품목이 여러 줄이면 합계만 보이고 고객명 패널에서 줄마다 고친다. 수량 미정 줄은 편집하지 않는다. 펜이 켜져 있거나 과거 날짜이거나 수정 권한이 없으면 보기만 된다. 팝업과 주문 목록은 같은 `items`(낙관적 사본)에서 계산하므로 어느 쪽에서 바꿔도 함께 바뀐다.
- **소리 지연**: (1) `order_items` 실시간 신호의 행을 지금 화면 스냅샷에 바로 반영해(`apply-item-change.ts`) 서버 화면을 기다리지 않고 알린다. (2) 서버 화면이 오면 기존처럼 직전 서버 화면과 비교하되, (1)이 이미 알린 같은 종류·업체·상품은 8초 안에 한 번 건너뛴다(중복 방지). (3) 첫 변경은 바로 알리고 직후 0.4초(최대 1.5초) 안에 뒤따르는 것만 모아 요약한다(이전: 1.5초 조용해질 때까지 대기, 최대 4초). (4) 화면 갱신 묶음 400ms → 150ms. 모르는 카드의 줄·`daily_businesses` 변경은 (2)가 알린다(여전히 갱신을 기다리지만 대기가 짧아졌다).
- **펜 속도**: 해상도는 유지(DPR 3, 3840×2160)하고 (1) 서버 데이터가 갱신될 때마다 캔버스가 전체 지워지던 것을 상품 줄 구성(id·취소)이 바뀔 때만 다시 그리게 했고 쓰는 중인 획은 그려 둔 구간까지 복원한다(`redrawLive`), (2) 획이 끝날 때 전체를 다시 그리지 않는다(이미 같은 모양으로 그려져 있다), (3) 획을 시작할 때 캔버스 위치를 한 번만 재고 점마다 레이아웃을 읽지 않는다, 펜의 상품 칸 위치 측정은 펜을 뗄 때 한 번만 한다. 효과는 칠판에서 측정하지 못했다(미측정). 더 필요하면 지우개의 획별 경계 상자 걸러내기, 진행 중 꼬리 구간 오버레이, DPR 상한을 후보로 둔다.

## 칠판 시험 후 변경 7 (별도 주문 팝업을 주문 목록과 같게)

- **펜**: 별도 주문 팝업에도 같은 그림 층을 얹었다(그릴 수 있는 기기는 쓰고, 그 밖의 기기는 서버 그림을 읽기 전용으로 본다, 숨기기 버튼도 같다). 팝업은 상품 칩 배치가 모니터 1·2와 달라 같은 문서를 쓰면 자유 필기가 엉뚱한 자리에 보이므로 `board_ink.monitor`에 `'s'`를 더해 따로 저장한다(마이그레이션 0058 — 체크 제약만 바꾼다). 팝업이 열려 있는 동안은 주문 목록 쪽 그림 층을 내려 펜 버튼이 하나만 보이게 한다. 팝업 안 목록이 스크롤되면 상품 칸에 붙은 획을 다시 그린다(상품 칸에 안 붙은 자유 필기는 스크롤하면 어긋난다).
- **고객명**: 팝업의 고객명을 누르면 주문 목록과 같은 패널(상품 추가·수정·미출고·취소·삭제, 주문 수정·삭제)이 열린다. 팝업의 상품 칩은 포장 완료만 되고 호버 버튼·`+` 버튼·주문 삭제 버튼은 뺐다. 그날 카드의 고객명만 바꾸는 연필 버튼(`renameDailyBusiness`)은 패널의 주문 수정(고객사 이름 자체를 바꾼다)과 달라서 그대로 둔다.
- **품목별 수량**: 팝업의 품목별 수량 칩도 같은 팝오버(포장 체크·수량 −/+·직접 입력)를 연다.
