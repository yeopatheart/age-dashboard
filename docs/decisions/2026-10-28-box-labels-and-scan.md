# 송장 라벨 출력 · 상차 스캔 · 업체 완료 표시 (2026-10-28)

## 결정
- **라벨 2종**: 박스 뚜껑 상단용(top)과 측면용(side). 크기(mm)와 항목(고정 문구·항목 값·바코드·구분선)의 위치·크기·글자를 **라벨 설정** 메뉴에서 자유롭게 편집한다(`label_templates`). 기본값은 상단 100×80mm, 측면 100×40mm(프린터를 정하면 바꾼다).
- **박스번호는 번호만** 찍는다(전체 박스 수 `1/3`을 쓰지 않음). 박스가 늘어도 이미 붙인 라벨을 다시 붙이지 않게 하려는 규칙이다.
- **바코드 12자리**(Code128): `YYMMDD(주문일) + 업체번호 3자리 + 박스 순번 2자리 + 확인 숫자 1자리`(`src/lib/labels/barcode.ts`). 확인 숫자는 EAN 방식이라 숫자 하나가 틀린 입력은 모두 걸러진다(테스트: 4400/4400). 상단·측면 라벨에 같은 번호를 찍어 어느 쪽을 스캔해도 같은 박스다.
- **라벨은 박스 할당 기록이 아니라 "업체 카드 + 박스 순번"에 붙인다**(`box_labels`). 박스 할당을 다시 제출하면 박스 행이 지워졌다 새로 만들어지므로, 거기에 붙이면 이미 붙인 라벨이 무효가 된다.
- **출력은 "확정"과 분리**: 박스 할당 화면의 "송장 라벨" 영역에서 박스 번호를 골라 상단/측면 라벨을 따로 출력한다. 새로 늘어난 박스는 "미출력"으로 나타나고(`미출력 박스 선택`으로 추가분만 출력), 훼손·분실은 그 번호를 골라 다시 출력한다(같은 바코드). 출력 이력은 `box_label_events`에 남는다.
- **상차 스캔 메뉴(`/scan`)**: 휴대폰 카메라(`@zxing/browser`, iOS 포함)나 블루투스 스캐너(키보드 입력 방식, 입력칸으로 들어온다)로 바코드를 스캔하면 `box_labels.loaded_at`이 채워진다(상차 완료). 이미 상차된 박스는 "이미 상차됨"으로 알리고, 잘못 스캔하면 되돌릴 수 있다. 터미널별·업체별 "상차 n/전체 m박스"를 보여준다.
- **대시보드 업체 완료 표시**: 취소되지 않은 상품이 있고 전부 포장 완료이거나 전량 미출고이면 업체명 앞에 `✓ 완료` 배지와 연한 초록 배경을 표시한다(수량 미정 상품이 있으면 완료가 아니다). 별도 주문 팝업에도 같은 배지(`isCardComplete`).
- 설정에 **상호·연락처** 입력 칸을 추가했다(라벨의 상호·연락처 항목에 찍힌다).
- 의존성: `jsbarcode`(바코드 그리기, MIT), `@zxing/browser`·`@zxing/library`(카메라 스캔, MIT). Code128 숫자 12자리를 JsBarcode가 만들고 ZXing이 읽는 왕복 테스트를 통과했다.

## 프린터·스캐너 추천 (조사 결과, 가격은 2026-10-28 다나와 등 최저가대, VAT 여부 확인 못 함)
- **환경이 얼음·물기·냉장이라 열전사(thermal transfer) + 합성지(PP) 라벨 + 왁스레진/레진 리본**이 맞다. 감열(direct thermal)은 열·습기에 약하고 수명이 짧다(감열 PP 라벨도 방습용으로 팔리므로 "절대 불가"는 아니다 — 며칠 쓰고 버리는 박스 라벨이라 현장 테스트가 필요하다).
- 프린터 1순위 **Bixolon XD5-40t**(약 50만원, 203dpi, 인쇄폭 108mm, 국내 제조), 2순위 **TSC TE210**(약 25만원, 감열·열전사 겸용, 보증 2년). Zebra ZD421t는 인쇄폭 104mm로 100mm 라벨에 여유가 적다. 203dpi면 Code128 12자리에 충분하다.
- 스캐너: **먼저 휴대폰 카메라**로 시작하고(추가 비용 없음), 현장 인식률이 낮으면 블루투스 스캐너(Honeywell Voyager XP 1472g 약 33만원, Zebra DS2278 약 30만원, 둘 다 IP42)를 추가한다. 물이 직접 닿으면 IP67인 Zebra DS3678(약 96만원)이 후보다.
- **확인 못 한 것**: 각 사 국내 AS 조건, Windows 드라이버·Chrome 인쇄 후기, 최소 라벨 높이(30~40mm 측면 라벨), 롤 교체 시 갭 센서 자동 인식, 열전사 합성지 롤 단가. 구매 전 샘플 롤과 리본으로 실제 박스·얼음 조건에서 하루 테스트한다.
- 얼음·결로에서는 라벨 소재보다 **접착제**(냉장·냉동용)가 더 큰 변수일 수 있다(추정).

## 알려진 한계 / 다음에 볼 것
- 출력 이력은 인쇄 대화상자를 열 때 남는다. 대화상자에서 취소해도 "출력 1회"로 기록된다(브라우저가 취소와 출력을 구분해 주지 않는다).
- 박스를 줄이면 번호가 남는 라벨은 화면에 경고만 하고 자동으로 무효 처리하지 않는다.
- 같은 프린터로 상단·측면 롤을 교체하면 Windows 드라이버의 용지 크기를 롤마다 바꿔야 한다(라벨 설정의 크기와 같아야 한다).
- 모바일 카메라 스캔은 HTTPS가 필요하다(배포 주소는 HTTPS). 젖은 라벨·결로에서의 인식률은 현장 테스트로 확인한다.
