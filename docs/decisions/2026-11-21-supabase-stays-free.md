# Supabase는 무료(Free) 플랜 유지 (2026-11-21)

## 결정
Supabase는 Pro로 전환하지 않고 **무료(Free) 플랜을 유지**한다.

## 왜 / 알고 있는 위험
- 성능은 계측상 병목이 아니고 어머니도 지장이 없다고 해서(`2026-11-21-perf-hold-after-telemetry.md`) 컴퓨트를 올릴 이유가 지금은 없다.
- **자동 백업이 없다**는 점은 알고 유지한다(Free 플랜 문서 전제, 사용자 화면에서 플랜 직접 확인은 기록에 없음). 필기·주문 데이터가 사라져도 DB 백업으로 되돌릴 수 없다.
- 대신 필기는 서버 이력(`board_ink_history`, 최근 2영업일)이 있고, 필요하면 수동으로 `board_ink` CSV를 백업한다(배포·큰 작업 전).

## 다시 볼 조건
- 데이터를 잃을 뻔한 일이 생기거나, 컴퓨트(CPU·연결 수)가 부족하다는 신호가 계측·Reports에서 보일 때.

## 대체하는 것
2026-11-20 성능 점검의 "Supabase Pro 전환 여부" 미결 항목.
