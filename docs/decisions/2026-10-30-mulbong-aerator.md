# 물봉 · 기포기 구분 — 2026-10-30

## 배경
형이 "보리새우 30미(일반, 물봉)"와 "보리새우 30미(일반, 기포기)"처럼 입력한다. 물봉은 물봉 안에 상품을 담는 것이고, 기포기는 물봉에 기포기를 부착해서 내보내는 것이다. 그런데 파서가 둘 다 `isMulbong`으로만 저장해서 구분이 사라졌고(주문 입력 괄호의 두 표기가 같은 줄), 대시보드에는 물봉 표시도 없었다.

## 결정
- `order_items.has_aerator`(0040) 추가. 기포기는 물봉도 함께 있는 것으로 저장한다(`is_mulbong = true`, `has_aerator = true`). 박스 추천은 둘 다 물봉 박스로 간다(기존 동작 유지).
- 준비 방식 `Prep`: 일반 / 물봉 / 기포기(`prepOf`, `src/lib/orders.ts`).
- **주문 입력**: 파서·AI 보정이 "기포기"를 별도로 인식한다. 같은 상품도 준비 방식이 다르면 별개 줄이다(기존 줄 찾기를 상품명 + 준비 방식으로 바꿈, 취소는 상품명만). 확인 화면에 물봉/기포기 칩을 보여준다.
- **표시**: 주문 목록의 상품 칸 괄호(PC·모바일), 박스 할당의 상품 칩(기포기 칩 신설, 물봉 칩은 주문의 물봉 표기에도 나옴).
- **합계**: 품목별 합계는 준비 방식별로 나눈다("보리새우 (일반) · 물봉", "보리새우 (일반) · 기포기"). 품목별 업체 목록도 같은 기준이다.
- **직접 입력**: 상품 추가·수정 창에 "포장 방식"(일반/물봉/기포기) 선택을 추가했다.

## 한계
- 이미 들어온 과거 주문은 기포기였는지 알 수 없어 물봉으로 남는다(0040 실행 뒤 새로 입력하는 주문부터 구분).
- 박스 할당의 박스 단위 "기포기 부착" 표시와 라벨 표시는 넣지 않았다. 필요하면 따로 정한다.
