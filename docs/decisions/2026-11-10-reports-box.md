# 2026-11-10 박스 리포트 (리포트 고도화 R1)

방향과 순서는 [reports-roadmap](2026-11-10-reports-roadmap.md). 이 문서는 박스 탭(`/reports/box`)에서 정한 정의와 한계다.

## 결정
- 리포트 위에 종류 탭을 둔다(주문 수량 · 박스). 이후 리포트가 생기면 `reports/report-tabs.tsx`에 한 줄씩 더한다. 박스 탭 안에서 **사용량 / 추천 정확도** 두 보기를 오간다. 기간은 일·주·월·년(기본 월), 권한은 `reports:view`.
- 표 기반이던 `/packing-log/accuracy`는 이 리포트로 **대체하고 삭제**했다. 박스 할당 화면의 "추천 정확도" 링크는 리포트 보기 권한이 있을 때만 보이고 `/reports/box?view=accuracy`로 간다.
- 박스 사용량의 기준은 **제출한 박스 구성**(`packing_boxes`, 박스 이름은 제출 시점 복사본)이다. 합포장·택배 여부와 무관하게 제출된 박스를 모두 센다. 기존 리포트의 박스 수(`daily_businesses.total_boxes`)와 다를 수 있다.
- **영업일 = 박스가 한 개라도 제출된 날.** 평균(개/일)은 쉬는 날을 빼고 구한다. 요일 칸은 그 요일 영업일 하루당 평균이다.
- 차트 색은 박스 종류 이름의 고정 순서(`boxes`의 생성 순서)로 정한다. 기간·필터가 바뀌어도 같은 박스는 같은 색이고, 8색을 넘거나 박스 목록에 없는(지웠거나 이름을 바꾼) 종류는 "기타"(회색)로 묶는다. 팔레트는 dataviz 스킬의 검증된 라이트 8색(인접 쌍 CVD ΔE 9.1)이고, 대비가 낮은 색이 있어 모든 차트에 범례와 "표로 보기"를 둔다.

## 추천 정확도의 정의
- 대상: 기간 안 `packing_records` 중 추천이 있던 것(`recommendation_id`). 재제출했으면 마지막 제출 기준이다.
- 1순위 일치 = `recommended_rank = 1`(제출한 박스 종류 구성이 1순위 후보와 같음, 상품 배치는 보지 않음), 후보 3 안 = `recommended_rank` 있음, 그대로 수락 = `accepted_as_is`(1순위의 박스별 상품 배치까지 같음). 박스 할당 화면의 기존 정확도와 같은 정의다.
- **추천과 실제의 차이(틀린 유형)**: 그대로 수락 / 박스 구성은 같고 상품 배치만 다름 / 후보 2·3순위를 선택 / 1순위와 박스 개수가 다름 / 개수는 같고 박스 종류가 다름 / (후보를 읽지 못함). 1순위 후보는 `packing_recommendations.candidates`에서 읽는다.
- **분해 축**: 신뢰도, 박스 수(1·2·3+), 주문 상품 줄 수, 물봉 박스 포함, 상품(그 상품이 들어 있을 때, 한 기록이 여러 상품이면 상품마다 한 번씩 센다), 업체, 터미널, 모델 버전. 순서가 없는 축은 1순위 일치가 낮은 순이고 **3건 미만은 "표본 부족"으로 따로 접어 둔다.** 항목이 많은 축은 위쪽 10개만 먼저 보인다.
- **최초 제출 vs 최종 제출**은 제출 이력(`packing_submit_events`, 0055)으로 본다. 이력은 0055 적용 뒤 제출분부터 쌓이므로 처음에는 비어 있다.
- 추이 차트는 비율(선)과 건수(막대)를 **두 차트로 나눴다**(축 하나 원칙). 건수가 없는 구간은 값이 null이라 선이 끊긴다(0%로 그리지 않는다). 1순위 일치와 그대로 수락이 같은 값이면 두 선이 겹치므로 그 사실을 부제에 적는다.

## 처음 읽은 운영 데이터 (2026-11-10, 11월 274건)
- 1순위 일치 46%, 후보 3 안 68%, 그대로 수락 46%.
- 신뢰도 높음 55% → 보통 39% → 낮음 28%(신뢰도는 방향이 맞다). 박스 1개 56% · 2개 27% · 3개 이상 0%. 물봉 박스 포함 33% vs 미포함 52%. 주문 줄 수 1~2줄 56% · 3~5줄 33%.
- 틀린 유형은 후보 2·3순위 선택 22%, 박스 개수가 다름 19%, 개수는 같고 종류가 다름 14%이고 **"구성은 같고 배치만 다름"은 0건**이다(1순위 일치 = 그대로 수락).

## 한계
- 재제출 이력이 없던 기간은 최초 제출 기준을 볼 수 없다.
- 사용량은 박스 **재고가 아니라 소진 속도**다. 재고·발주 알림은 별도 작업(roadmap).
- 데이터가 쌓이는 속도에 비해 모델 버전별 건수가 적은 버전이 있어 버전 비교는 참고용이다.
