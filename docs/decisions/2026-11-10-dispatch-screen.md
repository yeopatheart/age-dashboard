# 2026-11-10 보내기 화면 (퀵기사 / 고객사)

## 결정
- 탭은 **퀵기사 · 고객사** 두 개다(사용자 요청). 이전의 "영수증" 탭은 없앴다. 영수증 보기·삭제·보내기는 고객사 탭 안으로 옮겼고, **`/receipts` 메뉴와 페이지는 제거했다**(사용자 결정 2026-11-10: 고객사 탭의 미리보기로 충분). 리다이렉트는 두지 않는다.
- **보내기 아이콘은 퀵기사·고객사가 같다**(종이비행기). 둘 다 글을 카카오톡으로 보내는 같은 동작이라 통일했고, 크기도 다른 아이콘 버튼과 같다.
- **퀵기사**: 터미널마다 상차 완료 글. 버튼은 아이콘 둘 — 복사, 카카오톡 보내기(공유 시트). 공유 시트가 없는 컴퓨터에서는 보내기 아이콘이 비활성이고 복사를 쓴다. "카카오톡 보내기"는 카카오 SDK가 아니라 지금처럼 공유 시트다(사용자 결정: 추가 설정·키 없이).
- **고객사**: 그날 **정산이 끝난 고객사**만 올린다. 정산 완료 = 그 고객사의 판매내역 줄이 하나 이상이고 모든 줄에 판매가가 입력된 것(입금 여부와 무관, 사용자 결정). 판매가가 비어 있는 고객사는 목록 아래 "정산 미완료 N곳"에 이름만 보인다.
- 업체마다 아이콘 셋: **메세지 보내기** · 영수증 보내기 · 영수증 미리보기. 메세지는 공유 시트로, 공유 시트가 없으면 복사한다(아이콘은 그대로). 이름을 누르면 보낼 글을 펼쳐 볼 수 있다. 칩 순서: 영수증 N장 → 메세지 보냄 → 영수증 보냄.
- **메세지 글 형식**(사용자 제공): `감사합니다.` / `11/9 엔야 - 총 302,000` / `1. 활전갱이 3미1.3키로 : 39,000` … 날짜는 0 없이 월/일, 금액은 천 단위 쉼표, 줄은 판매내역 순서. 템플릿 설정 화면은 만들지 않았다(`src/lib/customer-message.ts`). **수량 글은 수량+단위 뒤에 부가중량을 "키로"로 이어 붙인다**(`3미` + 1.3kg → `3미1.3키로`, 부가중량이 없으면 `5.4키로`·`1박스`처럼 수량+단위만). 처음 구현에서는 부가중량이 판매내역 줄에 담기지 않아 빠져 있었고(2026-11-10 발견), 줄에 부가중량을 더하면서 고쳤다.
- **영수증 보내기**: 고객사의 영수증이 여러 장(사업자별, 15행 초과 시 쪽별)이면 공유 시트에 파일을 한 번에 넘긴다. 컴퓨터는 클립보드에 한 장만 들어가서, 한 장이면 복사하고 여러 장이면 미리보기 패널을 열어 장마다 보낸다. 영수증이 없으면 아이콘이 비활성이다.
- **영수증 미리보기**: 옆 패널에 영수증 화면과 같은 카드(크게 보기·보내기·삭제)를 그 고객사 것만 보여 준다. 삭제하면 `/dispatch`도 다시 읽는다(`revalidatePath`).
- 권한(마이그레이션 0054): 영수증 메뉴가 없어져 **영수증 권한을 정산 권한에 합쳤다.** 영수증 보기=`settlement:view`, 삭제=`settlement:edit`. 퀵기사 탭은 `scan:view`. 이전에 영수증 권한만 따로 받은(정산 권한은 없는) 사용자는 접근을 잃는다 — 정산은 매입가·수익이 보이는 화면이라 자동으로 정산 권한을 주지 않는다(0054 머리 주석의 조회로 먼저 확인).

## 구현
- 영수증 이미지(PNG)를 미리 만드는 로직을 `ReceiptsClient`에서 `use-receipt-images.ts`(직인·이미지 훅)로 분리했다. 영수증 화면과 고객사 탭이 같이 쓴다. 고객사 업체 줄이 화면 근처에 오면 화면 밖에 영수증을 그려 두고 한 장씩 이미지를 만든다(보내기를 누른 뒤에 만들면 모바일 공유 시트가 막힌다).
- 보냄 기록(`dispatch_log`): 고객사 메시지는 `kind='customer'`(마이그레이션 0053, key=고객명, 글 해시 포함), 영수증은 카드 키로 `kind='receipt'`. 기록 방식은 [2026-11-10-dispatch-log.md](2026-11-10-dispatch-log.md)와 같다.
- 0053 전에도 화면은 열린다. 고객사 메시지의 보냄 기록만 "0053 적용 필요"로 실패한다.

## 확인하지 못한 것
- 운영에서 0053 적용 뒤 메시지 보내기·영수증 보내기의 기록 흐름(이 문서를 쓸 때까지 0053은 운영에 적용 전).
- 모바일 공유 시트에 영수증 여러 장을 한 번에 넘기는 동작, 화면 밖에 그린 영수증의 이미지 품질(실제 휴대폰에서만 확인 가능).
- 메세지 글의 수량 표기가 실제 데이터에서 예시("3미1.3키로")와 같은지: 11/7 스시아타이는 "활전갱이 5미"로 나왔고, 예시처럼 두 단위가 붙는 품목은 품목명·수량·단위 입력 방식에 따라 달라질 수 있다.

## 하지 않은 것
- 일괄 보내기 큐(안 보낸 업체를 차례로 보내기), 택배·고객별 안내 글, `/receipts` 메뉴 제거, 하단 탭 변경.
