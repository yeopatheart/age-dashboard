# 상품 이름만 고친 경우는 모든 화면에서 "주문 변경"이 아니다 (2026-11-16)

## 결정 (사용자 확정)
제출한 박스가 있는 업체에서 주문 지문(이름 포함)이 달라졌더라도, **줄 수·각 줄의 단위·수량이 제출한 박스와 같으면(이름만 다름) 주문이 바뀐 것으로 보지 않는다.** 대시보드의 "박스 재확인" 경고(#181)와 박스 할당 메뉴의 "주문 변경" 칩(#191)이 같은 기준(`src/lib/packing/rename-only.ts`)을 쓴다.

## 왜
이름을 잘못 적어 고친 경우에는 박스를 다시 볼 필요가 없다. 한 화면에서만 경고가 사라지면 현장이 어느 쪽을 믿어야 할지 헷갈린다(오늘자 와쇼큐 유와).

## 경계
- 수량·단위·줄 수가 하나라도 다르면 경고는 그대로 뜬다. 제출한 박스 줄을 읽지 못하면(오류) 경고를 뺄 근거가 없으므로 경고한다.
- **미제출 업체의 "주문 변경"(추천을 다시 만든 경우)은 바꾸지 않는다.** 이름이 바뀌면 박스 추천 결과가 달라질 수 있다(가정, 미검증).
