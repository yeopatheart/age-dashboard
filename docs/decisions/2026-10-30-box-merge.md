# 합포장 · 수량 선택 입력 · 품목별 업체 목록 — 2026-10-30

## 합포장
- **무엇**: 포장이 끝난 뒤 한 고객 카드의 박스 2개 이상을 함께 테이핑해 내보내는 과정. 박스마다 라벨은 먼저 붙이되 라벨에 "합포장 1·2"가 찍혀 어떤 박스끼리 합칠지 알 수 있고, 합친 뒤에는 위에 올라온 라벨 하나만 보인다.
- **현장 순서**: 박스 할당 → 합포장 지정 → 라벨 출력(합포장 표시 포함) → 포장 → 합포장 테이핑 → 상차 스캔.
- **저장**: `daily_businesses.merge_groups`(jsonb, 예 `[[1,2],[4,5]]`, 마이그레이션 0039). 라벨처럼 고객 카드와 박스 순번에 붙여서 박스를 다시 제출해도 유지된다. 정규화·표시 문구는 `src/lib/box-merge.ts`.
- **지정**: 박스 할당의 라벨 영역에서 박스 번호 칩을 골라 "묶기"(권한 `packing:submit`). 박스 수를 줄여 번호가 사라지면 묶음에서 빠지고 2개 미만이면 해제된다.
- **라벨**: 새 항목 `합포장 표시`(`merge`)를 라벨 설정에서 원하는 위치에 직접 배치한다(고객명+박스번호에 합치면 글자가 너무 작아져 별도 항목으로 정함). 배치하기 전에는 라벨에 표시가 나오지 않는다. 합포장이 아닌 박스는 빈 글자다.
- **상차 스캔**: 묶음 중 하나를 스캔하면 같은 묶음 박스가 모두 상차 완료, 스캔 취소도 묶음 전체. 묶음 안에 아직 라벨을 출력하지 않은 박스는 라벨 행이 없어 상차 처리되지 않으며(라벨 출력 중 단계에 남는다) 출력하면 정상 처리된다.
- **표시**: 주문 목록(모바일 카드 태그, PC 박스 열)과 대시보드(현황) 고객 행에 `합포장`만 표시한다. 줄어든 박스 수는 보여주지 않는다.
- **알려진 한계**: 라벨을 출력한 뒤 합포장 지정을 바꾸면 이미 붙인 라벨은 옛 표시다. 화면에 "다시 출력하세요" 안내를 띄우지만(바꾼 직후 세션 동안만), 어떤 라벨이 옛 표시인지 DB에 기록하지는 않는다.

## 수량 선택 입력
- 주문 목록의 상품 추가·수정에서 수량 입력은 선택이다. 비우면 기존 "수량 미정"(수량 0·단위 없음)으로 저장하고 단위는 지운다. 수량을 쓰면 단위가 필요하다.

## 품목별 업체 목록(모바일)
- 품목별 화면에서 품목 행을 누르면 그 품목을 받는 업체와 업체별 수량이 펼쳐진다(포장 완료 표시, 미출고, 수량 미정 포함). 수량 미정은 품목 총계에는 안 넣는다. 같은 품목의 수량 미정 줄만 있고 확정 수량이 하나도 없으면 품목 행 자체가 나오지 않는다(총계가 없기 때문).
