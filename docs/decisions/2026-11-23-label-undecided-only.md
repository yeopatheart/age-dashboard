# 2026-11-23 수량 미정 상품뿐인 고객사도 라벨을 출력할 수 있게 한다

## 문제
라벨은 박스 할당을 제출한 박스에만 출력한다. 제출하려면 담을 상품이 1개 이상이어야 하고 빈 박스는 막혔다.
수량 미정(수량 0·단위 없음) 상품은 박스 목록에서 빠지므로, **상품이 전부 미정인 고객사**는 제출도 라벨 출력도 못 했다.
(확정 상품이 하나라도 섞인 고객사는 미정만 빠진 채로 제출·출력이 되므로 문제가 없었다.)

## 결정 (사용자 확정 2026-11-23: A안)
- 담을 상품이 0개이고 수량 미정 상품이 1개 이상인 고객사는 **빈 박스로 제출**할 수 있다(`emptyBoxesAllowed`, `src/lib/packing/box-rules.ts`). 서버(`submitPacking`)와 화면이 같은 규칙을 쓴다.
- 그 밖의 경우(확정 상품이 있는 고객사)는 지금처럼 빈 박스를 막는다. 상차 현황이 멈추는 문제는 박스가 실제로 없을 때 생기는 것이라 이 경우에는 해당하지 않는다(박스는 있고 안에 미정 상품이 들어간다).
- 전량 미출고만 있는 고객사는 현장에 없다는 사용자 확인으로 대상에서 뺐다.
- 나중에 수량을 채우면 기존 "주문 변경" 표시가 떠서 상품을 박스에 담아 다시 제출하게 된다(빈 박스는 그때부터 다시 막힌다).
- 빈 박스 기록은 박스 추천 학습에서 뺀다(`hasPackedItems`): "상품 0개에 박스 N개"는 박스 용량 추정을 틀어지게 한다.
- DB 변경 없음. 칠판 주문 목록 렌더링 코드는 건드리지 않았다.
