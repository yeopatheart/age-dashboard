# 라벨 프린터 변경과 라벨지 선택 (2026-11-12)

## 정한 것
1. **프린터는 4BARCODE 4B-2054L**(하이하이몰 스마트스토어 구매, 2026-11-12 도착)이다. 2026-11-06에 정했던 TSC TE210을 대체한다. 변경 이유는 세션에서 말해지지 않아 기록하지 않는다.
   - 사양(제품 사양표·매뉴얼 기준): **감열 전용(리본 없음)**, 203dpi, 152mm/s, 최대 인쇄폭 108mm, 용지폭 25.4~115mm, 40지관, USB. 연속지·갭·블랙마크 지원.
2. **라벨지는 100×80mm, 갭 라벨, 40지관, 감열 방식이어야 한다.** 리본을 못 쓰므로 열전사용 라벨은 맞지 않는다.
3. **라벨지 감열 여부 확인 순서**
   - 이미 주문한 nowfix 유포지 라벨(100×80mm, 700매/롤, 40지관): 상품 페이지에 감열/열전사 표기가 없고 열전사 리본을 추가 상품으로 판다 → **열전사용일 가능성이 높다**(미확정). 리본은 주문하지 않았다.
   - 2026-11-13 오전에 사용자가 nowfix에 문의한다. 감열이 아니면 **미개봉 상태로 반품**한다. 라벨이 와 있으면 앞면 긁기 테스트(검은 자국 = 감열)도 한다.
   - 대체 후보: 스마트스토어 kookjincom "감열유포지/100X80X500매/40지관 롤 라벨지/절취선", 500매/롤, 지관내경 4cm, 절취선 있음, 27,000원(최대할인가 24,300원)+배송 2,500원. 감열·방습 표기는 있으나 접착제 종류는 표기 없음.
   - 사용자는 2026-11-13 새벽에 새 라벨을 주문해 당일 발송을 요청하고 토요일(11/14) 도착을 기대한다. 이 판매처 배송 표기는 "영업일 기준, 주말·공휴일 제외"라 토요일 도착은 **불확실**하다.
   - nowfix 라벨이 감열로 확인되면 두 라벨을 출력해 비교한 뒤 추가 주문처를 정한다.
4. **비교 기준**(같은 프린터 설정·같은 디자인): 선명도, `/scan` QR 인식률(건조 10회), 물에 적신 뒤 인쇄 상태와 스캔, 얼음 결로 상자·스티로폼 접착(몇 시간 뒤), 갭 인식(연속 10장 이상).

## 대체하는 것
- `docs/decisions/2026-10-28-box-labels-and-scan.md`의 "젖음·얼음 환경 → 열전사 + 합성 라벨" 권고. 감열은 열·습기·긁힘에 약하다는 그 문서의 위험이 남아 있으므로 **현장 시험(11/14~15)으로 확인**한다.
- `docs/field-test-2026-11-14-checklist.md`의 A5(TSC TE210)와 C10("열전사 실물")은 낡았다. 갱신이 필요하다.

## 근거와 한계
- 감열/열전사 구분 근거: 4B-2054L 사양표의 "감열 라벨, 유포 감열 라벨" 표기, 4B-2054L 매뉴얼(manualslib 29쪽), kookjincom 상품 페이지(사용자가 보낸 캡처, 2026-11-12), nowfix 상품 페이지(2026-11-12).
- 확인 안 됨: nowfix 라벨의 실제 방식·접착제·갭, 롤 외경 한도, 롤 받침에 40mm 지관을 맞추는 부품(1.5" 부싱 등)이 기본 구성에 있는지, Windows 11 드라이버 설치 순서, Chrome 무음 인쇄 설정, 감열 라벨의 젖음·결로 내구성.
- smartstore.naver.com은 내장 브라우저·WebFetch·Claude in Chrome 모두 접근이 막혀 있어, 상품 정보는 사용자가 보낸 캡처로만 확인했다.
